# Phrabit iPhone音声翻訳プロトタイプ

## このコードの範囲

iOS 18以上を対象としたSwiftUIの録音画面と、WidgetKitのロック画面コントロールです。既定のアプリは `MockCaptureProcessor` を使い、録音内容にかかわらず固定サンプルを表示します。実サーバーの接続先・認証情報・AIキーは組み込んでいません。

- 初回に翻訳先を選び、マイクの使用を許可します。
- ロック画面のコントロールを押すとアプリを開き、設定済みなら録音を開始します。必要な端末認証を迂回しません。
- 録音は最大20秒で停止し、通常の成功・失敗・中断で一時ファイルを削除します。
- OSの強制終了時の即時削除は保証せず、次の起動で残存する試作録音を削除します。
- 固定サンプルは英語と中国語に分かれ、中国語にはピンインを表示します。
- 保存・ドリル・履歴・バックグラウンド録音は含みません。

この版は外部AIを利用するアプリではありません。録音内容の認識精度や翻訳品質の検証には使えません。

## 実接続用の準備コード

`CaptureHTTPProcessor` は、将来の音声認識と翻訳を別のPOSTへ送る通信部品です。既定のアプリからは生成しません。

- HTTPSの接続先と、明示的な外部送信同意の確認、トークン供給関数が必要です。
- 通信は録音停止後に行います。録音開始前にネットワーク応答を待つ処理はありません。
- Cookie・ディスクキャッシュ・HTTPリダイレクトを無効化します。
- 有料POSTを自動再試行せず、エラー時に固定サンプルへ切り替えません。
- セッションID、言語、原文が一致する応答だけを受け付けます。
- 音声認識後は録音ファイルを削除し、翻訳だけの手動再試行を行えます。
- 送信後の中断では、開始済みの外部処理や課金が取り消されると約束しません。

`CaptureCredentialStore` は、端末内Keychainへアプリ専用のデータを保存する部品です。実ログインのSDKとはまだ結線していません。OAuth・PKCE、認証SDKの版本固定、初回同意画面、実環境の認証は未実装です。UIから実通信を有効にする設定はありません。

## 構成

- `App/`: SwiftUI画面、録音、ViewModel、Keychainストレージ。
- `Core/`: 状態遷移、固定サンプル、通信クライアントとXCTest。
- `Control/`: ロック画面コントロール。
- `Shared/`: 本体とコントロールが共有する起動要求とシンボル。

SwiftUIは画面を作る仕組みで、翻訳モデルではありません。将来の実接続は既存Phrabitのサーバー処理を利用する設計です。

## 検証

`node scripts/check-ios-prototype.mjs` はソースと設定の静的検査です。Swiftのコンパイル・実行・マイク動作を証明するものではありません。

`swift test --package-path native/ios/PhrabitCapture/Core` で状態と通信のテストを実行します。通信テストはURLProtocolの固定応答で、実APIへ接続しません。

XcodeGenでプロジェクトを生成した後、本体と拡張の未署名Simulatorビルド・未署名iPhone archiveを検証します。署名・配布は別の手順です。このREADMEは実行結果や実機合格を保証しません。

マイク許可・拒否、先頭音、コールド起動、連打、画面を閉じる操作、着信、VoiceOverの確認には実機が必要です。

## プライバシー

現在の既定動作は外部送信なしの模擬版です。実通信を有効にする前に、送信先と目的の説明・明示同意、認証、予算制御、プライバシー宣言を見直す必要があります。端末側のAPIキー埋込みは行いません。
